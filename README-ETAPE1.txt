AYEGLE REACT - ETAPE 1 - SPCK EDITOR (Camon 30)
==============================================
1. Dans Spck, clique sur le menu (3 barres en haut a gauche)
2. Cree un NOUVEAU PROJET / NOUVEAU DOSSIER : AYEGLE-REACT
3. Cree 3 fichiers dans ce dossier :
   - index.html (coller le contenu de index.html)
   - App.jsx (coller le contenu de App.jsx)
   - App.css (coller le contenu de App.css)
4. Ouvre index.html > bouton Apercu / Play
5. Tu dois voir : AYEGLE + 3 cartes EBOGA / OMBIRI / DISSOUMBA + barre en bas
6. Clique sur chaque carte : ca change de page. C'est ca, React !

ETAPE 2 (apres) : on met ton vrai contenu EBOGA dedans, sans tronquer.
MBOKA : on ne touche pas.
