# AYEGLE — École Spirituelle

Apprendre — Pratiquer — Transmettre

## Les 3 voies

- **AYEGLE ÉBOGA** : Enseignements, prières, pratique
- **AYEGLE OMBIRI** : Temple de la Sagesse, prières modifiables, ESSAMA
- **AYEGLE DISSOUMBA** : Notes, rituels, mémoire

## KÉNGUÉ

## Comment lancer

1. Ouvrir `index.html` dans un navigateur
2. Ou : dans Spck Editor, cliquer sur Aperçu

## Technologies

- React 18 (sans build, avec fichiers séparés)
- CSS Sacré Premium : or + vert forêt
- Stockage local (localStorage) — aucune donnée ne quitte le téléphone
